# 🍫 Bolo de Chocolate Simples

Uma página web responsiva com receita de bolo de chocolate usando HTML e CSS puro.

## 📋 Pré-requisitos
- Navegador moderno

## 🛠️ Tecnologias
- HTML5
- CSS3

## 🚀 Execução
1. Clone o projeto:
```bash
git clone https://github.com/Marcuslaf/in100tiva_desafio_02
```

2. Abra index.html no navegador
